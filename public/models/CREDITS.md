# 3D muscle model credits

`muscles.glb` is adapted from **Z-Anatomy — The libre 3D atlas of anatomy**
by Gauthier Kervyn, based on **BodyParts3D — The Database Center for Life
Science** (Kousaku Okubo), via the community-prepared region/material split
in [kalibismail/hoik-muscle-model](https://github.com/kalibismail/hoik-muscle-model)
(no code from that project is used — only its redistribution of the derived
GLB, which documents the exact muscle→region joins and decimation applied).
